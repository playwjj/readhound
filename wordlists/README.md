# 分年级字表数据

## 这是什么

统编版小学语文「生字表」（会写字）按学期整理：每个字首次出现的学期。
`grade1-4-writing.csv`：1 上–4 下共 1,794 个不重复字；
`grade1-4-writing.json`：各学期末累计不重复字数 + 跨学期重复的 6 个字。

| 学期末 | 当期新字 | 累计不重复字 |
|---|---|---|
| 1 上 | 100 | 100 |
| 1 下 | 200 | 300 |
| 2 上 | 250 | 550 |
| 2 下 | 249 | 799 |
| 3 上 | 250 | 1,049 |
| 3 下 | 248 | 1,297 |
| 4 上 | 248 | **1,545** |
| 4 下 | 249 | 1,794 |

提案 §9 的白名单基线（1–3 年级 + 4 上）= **1,545 字**。

## 来源与校验

- 来源：an2.net《统编版小学语文生字汇总表（2019版）》
  <https://www.an2.net/tools/primary-characters>（2026-11-25 拉取）
- 校验：逐学期抓取的字数与页面标注完全一致（100 / 200 / 250×6）；
  跨学期重复仅 6 字（句、胡、理、段、帝、启，各出现两次，多为多音/复现教学），
  已按首次出现学期归一，重复不计入累计。
- 五、六年级同源数据未收录（页面 6 下段混入页脚内容，计数不可信；一期用不到）。

## 重要口径：这只是「会写」字，不是「会认」字

- 课标（2022 年版）：1–2 年级认识 1,600–1,800 字（其中 800–1,000 会写）；
  3–4 年级累计认识 2,500 字（其中约 2,000 会写）。
- 本表是会写字，天然比认读量小。用它做「已掌握字表」基线会**系统性偏严**：
  样例报告里，考、德、基、标、律、译这类孩子大概率会认的字也被判生字。
- 正确做法（提案 §5 不变）：**冷启动识字测评实测孩子的已掌握字表**，
  那才是难度引擎的真正输入；本表只作标准参照与兜底。

## 识字表（认读字）：已接入 `src/data/textbook.js`

- 来源：Zhang, Guo et al. (2023) *A large-scale database of Chinese characters
  and words collected from elementary school textbooks*, Behavior Research
  Methods；数据 <https://osf.io/ynk8c/>（`Character.xlsx`，教育部统编小学
  语文教材，2,999 字，逐字标注册次与 识字表/写字表）。
- 生成：`python3 -I scripts/build-textbook.py Character.xlsx`。
- 认读累计：一上 300 → 一下 700 → 二上 1,150 → 二下 1,599 → 三上 1,850 →
  三下 2,100 → 四上 2,350 → **四下 2,597**，与课标「3–4 年级累计 2,500」吻合。
- 交叉校验：其中的写字表（一上–四下 1,797 字）与本目录 an2.net 会写字表
  （1,794 字）重合 **1,766 字（98%）**；各约 28 字之差应为教材版次差异。
- 现在引擎的字序 = 首次认读册次（册内按字频）；会写册次保留作第二层
  （生字卡显示「X 册认识，Y 册会写」，三期书写训练用）。
